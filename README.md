# AutoML Hub – Automated Machine Learning Model Training and Management Platform

## Project Overview
AutoML Hub is a web-based platform that simplifies the machine learning workflow. It allows users to upload datasets, select a target column, and evaluate suitable machine learning algorithms based on their performance.

## Features
- Upload CSV datasets
- Analyze dataset structure and columns
- Preprocess data for machine learning
- Identify the problem type
- Select suitable machine learning algorithms
- Train and evaluate models
- Compare model performance metrics
- Manage experiments
- Store model evaluation results in a model registry

## Technology Stack
- **Frontend:** Angular
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Machine Learning:** Python, Scikit-learn

## How It Works
1. Upload a CSV dataset.
2. Select the target column.
3. Validate and preprocess the dataset.
4. Identify the machine learning problem type.
5. Train suitable algorithms.
6. Evaluate and compare model performance.
7. View the results and store relevant model information.

## Installation and Setup
1. Clone the repository.
2. Install the frontend and backend dependencies.
3. Configure the MongoDB connection.
4. Start the backend server.
5. Start the Angular frontend.

Refer to the project configuration files for the exact commands and settings.

## Project Objective
To simplify machine learning model selection and evaluation by helping users identify suitable algorithms for their datasets.
